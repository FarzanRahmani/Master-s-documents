# مجوز و انتساب

هستهٔ اولیهٔ این قالب بر پایهٔ پروژهٔ **A LaTeX Template for Typesetting
Theses in Persian** اثر Hamid Zarrabi-Zadeh و مشارکت‌کنندگان آن تهیه شده است:

<https://github.com/zarrabi/thesis-template>

قالب اصلی تحت مجوز **Creative Commons Attribution 4.0 International
(CC BY 4.0)** منتشر شده است:

<https://creativecommons.org/licenses/by/4.0/>

این نسخه برای استفادهٔ عمومی بازآرایی شده و اصلاحات سازگاری XeLaTeX، صفحه‌های
ابتدایی قابل‌تنظیم، راهنمای فارسی و نمونه‌های خنثی به آن افزوده شده است. هنگام
بازنشر یا اقتباس، انتساب فوق و پیوند مجوز را حفظ کنید.
